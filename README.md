# Vidya Placement Management System (VPMS)

A modern web-based Placement Management System designed for **Vidya India**, an NGO focused on skill development and employment opportunities for underprivileged youth.

This platform helps placement coordinators efficiently manage student profiles, job postings, applications, interviews, placements, and post-placement tracking through a centralized dashboard.

---

## ✨ Features

### 👨‍🎓 Student Portal
- Create and manage student profiles
- Upload resume and certificates
- View and apply for jobs
- Track application status
- Resume builder (UI)

### 👩‍💼 Admin Portal
- Dashboard with placement statistics
- Student management
- Job posting management
- Application tracking
- Interview management
- Placement tracking
- Reports & Analytics
- Notifications

### 📊 Dashboard
- Total Students
- Certified Students
- Active Jobs
- Applications
- Interviews
- Placed Students
- Placement Trends
- Salary Distribution

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/vpms.git
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
